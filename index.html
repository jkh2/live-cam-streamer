Settings

With a key, Now Here can (1) check which catalog cams are live right now and hide the rest, and (2) search all of YouTube Live for any place, showing only streams that are live and that their owners allow to be embedded. The key stays in this browser and is only sent to Google. Get one free at Google Cloud Console → enable “YouTube Data API v3” → Credentials → API key. Restricting it to your site’s address is a good idea.

Now Here

Every light on this globe is a live camera somebody chose to share with the world: a town square, a waterhole, a harbor, a feeder, an aurora cam. The globe’s sunlight is real and calculated for this moment, so you can watch day turn to night across the planet and catch the sunrise wherever it is happening now.

Our rule

  • Live video only. No recordings, no replays, no still-image cams.
  • Only cameras published on purpose. Every stream comes from its owner’s public channel, with embedding allowed by that owner. We never scan the internet for cameras, and never show unsecured, private, or “found” cameras.
  • Owners stay in control. If an owner turns off embedding or ends the stream, it disappears from Now Here. If you think a camera doesn’t belong, press ⚑ on it.
